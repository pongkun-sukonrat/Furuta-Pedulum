## Project Overview

This project focuses on the modeling, simulation, and control of a Furuta Pendulum (Rotary Inverted Pendulum). The project includes CAD design, multibody dynamic modeling, and control system development to investigate the stabilization of an inherently unstable system.

## Contents

### MATLAB Simulation
MATLAB scripts used for dynamic modeling, system analysis, controller design, and simulation.

### Simscape Multibody Model
A physics-based multibody model of the Furuta Pendulum developed using Simscape Multibody for dynamic simulation and visualization.

### Fusion 360 CAD Model
Complete CAD assembly and component designs of the Furuta Pendulum created in Autodesk Fusion 360.
